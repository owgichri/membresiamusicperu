# DJ Music Perú — Landing de membresías

Página estática (HTML + CSS + JS) publicada en Vercel.

- `index.html` — la página (plantilla dentro de `<template id="dc-tpl">`)
- `js/app.js` — lógica (planes, reproductor, testimonios, cookies…)
- `js/dc-lite.js` + `js/preact.min.js` — motor de dibujo (Preact, licencia MIT)
- `js/consent-pixels.js` — Meta / TikTok Pixel con consentimiento
- `tracks.json` + `previews/` — Top 10 del reproductor (audios cifrados con marca de agua)
- `assets/img/` — logos, flyers, fotos y medios de pago
- `herramientas/preparar_top10.pyw` — programa para preparar nuevas canciones

Para actualizar el Top 10 lee **COMO-ACTUALIZAR.md**.
